每个阶段入口都链接到固定提交下的完整源码、文档、结果和 ZIP 下载。固定提交不会随着 main 更新而改变；所有原始 Git 历史保留，没有重写历史，也没有把旧报告描述成当前接口。

需要重跑旧版时，下载对应阶段的完整 ZIP，在独立目录按那个版本的 README 安装。不要只取一个旧求解器文件放进当前包；同名模块和旧 PDE 数据接口可能不同。旧版测试结果是该阶段记录，本次发布未重新执行所有历史版本。

当前程序只在 01_程序/cdr 维护；培训和实验说明分别更新相应目录。出现新的能力阶段时，再在本档案增加入口，既保留可追溯性，也避免保存多套容易不同步的源码副本。

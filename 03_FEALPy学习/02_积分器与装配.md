# 02 积分器与装配

## 一条积分公式的分工

数学上 Kᵢⱼ=∫a∇φⱼ·∇φᵢ。FEALPy 将这件事拆成两个层次：积分器生成各单元的局部矩阵；BilinearForm 按自由度映射装成全局稀疏矩阵。

读取 fealpy/fem/scalar_diffusion_integrator.py 的默认 assembly 路径，顺序是：

1. 取得求积点 bcs 和权重 ws。
2. 取得单元大小 cm。
3. 处理系数：若 coef 是函数，在合适坐标求值。
4. 取得物理坐标下的基函数梯度 gphi。
5. 调用 bilinear_integral，把梯度、权重、单元大小与系数相乘求和。

局部矩阵通常形如 (NC,ldof,ldof)：单元数、每单元自由度数、每单元自由度数。它不是最终 (N,N) 全局矩阵。

然后读 scalar_mass_integrator.py、scalar_convection_integrator.py、scalar_source_integrator.py。每次只问：试探一侧用基函数本身还是梯度？测试一侧用什么？系数是标量还是向量？这样能对应程序主讲义的五行表。

## 在本项目中怎样调用

```python
from fealpy.fem import BilinearForm, ScalarDiffusionIntegrator
form = BilinearForm(solver.scalar_space)
form.add_integrator(ScalarDiffusionIntegrator(coef=1.0, q=5))
K = form.assembly()
print(K.shape)
```

该片段接在最小例子创建 solver 之后。这里 form 和积分器都来自 FEALPy，coef=1.0 是使用者给的数据。K 是扩散矩阵，还没有应用边界，因此不要直接拿它解零边界问题就误以为完整系统已经建立。

读取 fealpy/fem/bilinear_form.py 与 linear_form.py，关注 assembly 和局部到全局映射。COO 存储记录“行编号、列编号、值”；共享位置会有多份贡献，合并后相加。CSR 适合按行访问和后续求解。这不是先建立一个巨大稠密零表再填数。

## 分块系统

fealpy/fem/block_form.py 的 BlockForm 负责子块的行列偏移和组合。本项目传入二维列表 forms[i][j]。局部物质 i 的第 k 个自由度在长向量里对应 iN+k（从零编号）。这解释了为什么原来的 N×N 子块成为 mN×mN 系统。

ConstIntegrator 位于 fealpy/fem/integrator.py，允许将已计算好的局部数组接入装配。本项目 SUPG 用它接入自定义 blocks、mass、loads。库负责装配，项目负责这些局部数值公式，二者边界清楚。

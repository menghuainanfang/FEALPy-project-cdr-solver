# CDR 程序入门讲义

这份讲义从“如何运行一个 Python 文件”讲到“如何读懂本项目求解过程”。零基础读者可以按学习路线分多次完成，不必一次看完。每一节先理解输入、输出，再看内部细节。数学符号不熟悉时，回看数学讲义第 0.1 和 15 节。

## 1. 先分清三样东西

Python 解释器负责执行 .py 文件，相当于读懂程序语言的工具；FEALPy 是已安装的有限元计算库；cdr 是本项目编写的 CDR 求解包。解释器不是求解器，库提供部件，项目把部件组织为这个问题的求解流程。

| 写法 | 属于谁 | 做什么 |
|---|---|---|
| from fealpy.backend import backend_manager as bm | FEALPy | 引入数组运算后端管理器 |
| from fealpy.mesh import TriangleMesh | FEALPy | 引入三角网格类型 |
| LagrangeFESpace、TensorFunctionSpace | FEALPy | 构造标量与多分量函数空间 |
| BilinearForm、LinearForm、BlockForm | FEALPy | 管理与装配矩阵、向量、分块系统 |
| DirichletBC、spsolve | FEALPy | 处理边界、求解线性方程组 |
| from cdr import CDRSolver, box_mesh | 本项目 | 引入 CDR 流程和统一网格入口 |
| CDRModel、SymbolicCDR、at_time | 本项目 | 约定方程数据、符号模型、固定时间 |
| supg_terms | 本项目 | 计算 SUPG 局部修正 |
| numpy、sympy、scipy、vtk | 其他依赖 | 数组、符号运算、稀疏求解、结果文件 |

例如 box_mesh 内部调用 FEALPy 网格构造器，但 box_mesh 这个名字不因此变成 FEALPy 的接口。本文所说“我们的接口”，都指 cdr/ 内定义的东西。

## 2. 不懂编程时，先会读这些符号

Python 按语句执行。a=3 是把 3 绑定到名字 a，不是数学上证明相等；判断相等用 ==。# 后是注释，不参与计算。字符串用引号包围，例如 "numpy"。列表 [1,2,3] 是有顺序的一组对象，下标从 0 开始。

函数是可重复调用的一段过程。def double(x): 后缩进的 return 2*x，表示输入 x 后返回两倍。double(3) 得到 6。关键词参数 n=2 表示把参数 n 设成 2；不能只凭数字猜它是步长还是步数。

class 定义一类对象；obj.method(...) 调用这个对象的方法。self 表示方法正在操作的那个对象。__init__ 在创建对象时保存参数、建立内部数据，不等于已经计算出方程的解。例如创建 CDRSolver 时会建函数空间；真正求解发生在 solve_steady 或 solve_time。

import 是引入已有代码。from A import B 表示从模块 A 引入名字 B；as bm 只是给名字取简称。from .pde import at_time 的点表示同一个 cdr 包里的 pde.py。

缩进是 Python 语法的一部分。复制例子时保留缩进；在命令行运行 python example_minimal.py，而不是把整段命令输入 Python 的 >>> 提示符。

## 3. 第一个可以手算对照的程序

先按程序文件夹 README 安装。进入 01_程序，运行：

~~~text
python example_minimal.py
~~~

应看到按坐标排序的三个节点 [0,0.5,1] 和数值 [0,0.25,0]。对应数学讲义第 15 节 −u''=2、两端为零。

~~~python
from fealpy.backend import backend_manager as bm
from cdr import SymbolicCDR, CDRSolver, box_mesh

bm.set_backend("numpy")
pde = SymbolicCDR(dim=1, exact=["x*(1-x)"])
mesh = box_mesh(pde, n=2)
solver = CDRSolver(pde, mesh, p=1, stabilization="galerkin")
uh = solver.solve_steady()
~~~

逐句理解：

1. 前两行引入现成名字；第一行来自 FEALPy，第二行来自项目。
2. 明确选择 NumPy 后端。本项目不会在 import 时悄悄替使用者切换后端。
3. pde 是一份方程数据。dim=1 是空间一维；exact 列表只有一个表达式，因此物质数为 1。SymbolicCDR 自动从真解生成 source=2。
4. n=2 是每条坐标边划分的段数，不是最终节点数。这里两段产生三个节点。
5. p=1 选择一次拉格朗日元；galerkin 不加 SUPG。这个简单扩散问题不需要迎风修正。
6. solve_steady 组装并求解，返回有限元函数 uh。uh[:] 是它的系数数组；uh 还可以在规定的坐标形式上求值，不能把它理解成只有三个数字的普通列表。

exact 在此用于验证，不是所有实际问题都必须提供。真实输入方式见第 12 节。

## 4. 网格与自由度：n、p、dim、components 分别是什么

dim 决定几维空间；components 决定几种物质；n 决定网格划分密度；p 决定每个单元里使用几次多项式。四者不可混淆。

box_mesh 是项目的便捷函数。它读取 pde.domain()，然后：

- 一维调用 FEALPy 的 IntervalMesh.from_interval_domain。
- 二维调用 TriangleMesh.from_box，分别设置 nx=n、ny=n。
- 三维调用 TetrahedronMesh.from_box，分别设置 nx、ny、nz。

二维 n=4 指正方形每边四段，每个小方格再分为两个三角形，总计 32 个三角形。P1 标量自由度是 25；P2 除顶点外还增加边中点，共 81。若有三个物质，长向量长度就是 3×81=243。不是“网格变成 243 个三角形”。

可以在创建 solver 后查看：

~~~python
print(mesh.number_of_cells())
print(solver.scalar_space.number_of_global_dofs())
print(solver.space.number_of_global_dofs())
print(solver.scalar_space.interpolation_points().shape)
~~~

scalar_space 是 FEALPy LagrangeFESpace；space 是 FEALPy TensorFunctionSpace。项目采用 shape=(components,-1) 的布局：同一物质的全部自由度连续排列，再排下一个物质。

## 5. 最重要的数组语言

NumPy 数组是一张规则排列的数表。shape 是每个方向的长度；例如 (3,2) 是三行两列。点数组 points=[[0,0],[1,0],[0,1]] 的 shape 为 (3,2)：三个位于二维空间的点。

points[...,0] 取所有点的第一坐标；... 表示保留前面所有维度。不能固定写 points[:,0] 处理所有场景，因为积分点常常按“单元、积分点、坐标”排列，shape 可能是 (NC,NQ,2)。

项目用 S 表示点数组除最后坐标轴之外的所有轴，D 表示空间维数，m 表示物质数：

| 方法 | 返回形状 | 例如 3 个二维点、2 个物质 |
|---|---|---|
| diffusion_coef、capacity_coef | S | (3,) |
| convection_coef、diffusion_gradient | S+(D,) | (3,2) |
| reaction_coef | S+(m,m) | (3,2,2) |
| source、solution、dirichlet、initial | S+(m,) | (3,2) |
| gradient | S+(m,D) | (3,2,2) |

diffusion_gradient 返回扩散系数 a 的空间梯度；gradient 返回精确解的空间梯度，两者不同。即使只有一个物质，source 也要返回 (3,1)，不能随意省去末尾的 1。物质轴和空间坐标轴恰好都可能长度为 2，但含义不同。

假设两节点、两物质的数据是 [[10,20],[11,21]]，每行是一个节点。项目用 .T.reshape(-1) 得到 [10,11,20,21]。T 交换这张二维表的行列；reshape(-1) 拉平。所以“物质一整段，然后物质二整段”的布局来自明确的排列规则。

## 6. 模型文件 pde.py：向求解器提供什么

CDRModel 是项目基类。它保存维数、物质数和盒形区域，提供边界识别、默认初值与边界值。默认 initial 调用 solution(p,0)，默认 dirichlet 调用 solution(p,t)。没有精确解时，必须提供真实的初值和边界，不能依赖这个默认值。

SymbolicCDR 是它的子类：借助 SymPy 把字符串表达式变成可在数组上计算的函数。它自动计算偏导、源项和精确梯度，用来做制造解很方便。字符串 "x*(1-x)" 是数学表达式，不是 Python 回调函数。

@cartesian 来自 FEALPy，是坐标约定的标记，让积分器知道该函数接收真实物理坐标。它不会替任意 Python 函数求导，也不是一个解释器。自动求导出现在 SymbolicCDR 调用 SymPy 的部分。

at_time 来自项目，作用是把“两参数函数 function(p,t)”变成“只接收点的函数 evaluate(p)”。例如固定 t=0.5 后，FEALPy 积分器只需要传点，内部仍会用保存的 0.5 调用原函数。component=(i,j) 再取反应矩阵的第 i 行、第 j 列。

为什么这样适配？FEALPy 标量积分器要的是一个标量系数函数，而我们的 PDE 数据同时含时间和物质轴。适配函数把多出来的维度在正确位置取出，不修改 FEALPy 积分器。

## 7. assemble：把公式变成矩阵

阅读 solver.py 的 assemble(t)，先只看 Galerkin 分支。对应数学式为 M U̇+A U=F，A 含扩散、对流和反应。

| 数学项 | FEALPy 对象 | 项目传入的数据 |
|---|---|---|
| ∫a∇φⱼ·∇φᵢ | ScalarDiffusionIntegrator | 固定时间后的 a |
| ∫(b·∇φⱼ)φᵢ | ScalarConvectionIntegrator | 固定时间后的 b |
| ∫Cᵣₛφⱼφᵢ | ScalarMassIntegrator | C 的第 r,s 项 |
| ∫dφⱼφᵢ | ScalarMassIntegrator | 容量 d |
| ∫fᵣφᵢ | ScalarSourceIntegrator | f 的第 r 项 |

BilinearForm 是装矩阵项的容器；LinearForm 是装右端项的容器。add_integrator 是把一条积分规则交给容器；assembly 才产生装配结果。不要把 add_integrator 的返回值当成最终矩阵。

外层循环 i 表示正在构造哪个物质的方程，内层 j 表示这一方程里哪个物质的未知量。反应项可能存在于每一块。当前模型没有跨物质扩散或对流，所以只有 i==j 时添加扩散、对流。BlockForm 把这些标量子块装成大矩阵。

局部到全局映射来自 space.cell_to_dof()：它告诉程序某个三角形的局部第 0、1、2 个自由度，对应全局的哪几个位置。装配就是沿这张映射，把相邻单元在共享自由度上的贡献相加。数学讲义两段线元的中间对角线 2+2=4，正是这个动作。

返回顺序是 A,M,F，不是 M,A,F。读调用端时要按实际函数返回顺序接收。数值求积次数 q 默认 p+4，与 p 是两个参数；q 控制积分精细程度，不直接增加未知数。

## 8. _solve：先处理边界，再求长向量

_solve 是项目内部方法，名字以下划线开头表示通常不直接调用。它做三件事：

1. 调用 FEALPy DirichletBC(...).apply(A,F)，把已知边界和对内部方程的影响一起处理。
2. 调用 FEALPy spsolve(...,solver="scipy")，或用户提供的 linear_solver 回调。
3. 把解放进 FEALPy 有限元函数对象，并记录残差与边界误差。

线性求解器接收矩阵和右端，返回全部物质的系数；它并不知道“温度”还是“浓度”。PDE 的含义已经进入矩阵、右端和边界。

不应先独立求完物质一再求物质二，因为第一条方程通常也含未知的物质二。这里一次求整个块系统。若要分裂或迭代求解，需要另外设计方法，不是改一下循环顺序即可。

history 中 residual 检查 A@U−F 的相对量级；boundary_error 检查边界值。两者小是必要证据，不代替与真解比较或网格收敛。

## 9. solve_time：两个数字究竟是什么

~~~python
uh = solver.solve_time(0.8, 4)
~~~

第一个参数 end_time=0.8 是终止时刻；第二个 steps=4 是总步数。内部算 dt=0.8/4=0.2，依次走到 0.2、0.4、0.6、0.8。不能把 0.8 理解成步长。当前时间起点固定为 0，步长固定。

old 保存上一层 Uⁿ；previous 保存上上层 Uⁿ⁻¹。默认 scheme="bdf2"，即二阶后向差分公式。第一步没有上上层数据，用后向欧拉法：

(M+dt A)U¹=M U⁰+dt F。

后续用：

(1.5M+dt A)Uⁿ⁺¹=M(2Uⁿ−0.5Uⁿ⁻¹)+dt F。

每一步都在新时刻重装 A,M,F，因此系数随时间变化时不会沿用旧系数。这里时间项是 d(t)u_t，不是 ∂ₜ(d(t)u)，所以没有额外的 d_t u，也不是对 dU 做 BDF2。

previous,old=old,uh[:].copy() 表示右边先求出，再一起赋值；copy 保留这一层数据，避免下一次更新对象时覆盖历史。

## 10. stabilization.py：第二遍再读的部分

SUPG 是流线迎风彼得罗夫—伽辽金法。它是项目自己实现的局部数值扩展，不是声称调用了 FEALPy 中一个同名 CDR 稳定化求解器。

先用 FEALPy 取得积分点、权重、单元面积/体积、基函数 phi、梯度 grad；再在这些点求 a、b、C、d 和源项。streamline=b·∇phi，test=τ×streamline。trial 的构造包含对流、扩散二阶项、变扩散系数梯度项以及反应。

p=1 时仿射单元内基函数二阶导数为零；p=2 时不能省去。残差扩散项是 −aΔphi−∇a·∇phi。稳定化的质量修正与载荷修正也同时返回，不只修改空间矩阵。

einsum 是“按索引乘积再求和”的简写。例如 q 是积分点编号，i、j 是局部自由度；对 q 求和时，乘权重、单元大小、测试值和试探值，留下 i,j 两个轴，于是得到局部矩阵。c 作为单元轴保留下来。先读懂这句话，再逐项核对下标，不必一开始背整条 einsum。

supg_terms 返回局部 blocks、mass、loads。项目通过 FEALPy ConstIntegrator 将已经算好的局部数组交给装配流程；ConstIntegrator 属于 FEALPy，局部数组的计算公式属于本项目。

## 11. 结果怎么读，测试在保证什么

errors(t) 用 FEALPy mesh.error 对函数值和梯度误差做数值积分，要求模型提供精确 solution 和 gradient。实际未知真解问题不调用它；可以做网格加密比较或与实验、参考数据比较。

export_vtu 输出每个物质的 u_i 和模长。PVD 串起各个时刻，ParaView 可播放。P2 结果导出时只在网格顶点采样，因此不应把 VTU 的线性插值图当成完整二次有限元函数。

verify_vector.py 检查空间收敛、时间收敛、制造解一致性、非对角反应耦合、强对流边界层以及 VTU 读回。verify_vector_interfaces.py 检查导入不修改 FEALPy 名字空间、不同实例不互相污染、四分量、无真解模型、线性求解回调等。

测试失败时，先看哪一类证据不成立：边界不对检查 boundary/dirichlet；空间阶不对检查系数、积分和自由度；时间阶不对检查起步与历史；形状不对检查物质轴。不要先通过放宽断言让测试变绿。

## 12. 不给精确解，也能求实际输入问题

以下代码可以接在导入之后：

~~~python
pde = SymbolicCDR(
    dim=1, components=1,
    source=["2"], boundary=["0"], initial=["0"],
    a=1, b=[0], reaction=0, d=1
)
solver = CDRSolver(pde, box_mesh(pde, n=8), p=1,
                   stabilization="galerkin")
uh = solver.solve_steady()
print(uh[:])
~~~

这里程序并不知道精确解。source 是杆内产热，boundary 是两端温度，initial 供含时求解使用，稳态不使用初值。若改成 solve_time(1.0,20)，则从全零初值开始，逐步向稳态演化。

也可以继承 CDRModel，自己用数组运算实现系数方法。这样更接近 FEALPy 常见 PDE 数据类风格，但要严格遵守第 5 节的数组形状；先用 SymbolicCDR 验证问题，再写数组版本做结果对照，逐步掌握两种方式。

## 13. 对外接口速查

CDRSolver(pde,mesh,p=1,stabilization="supg",q=None,linear_solver=None)：创建项目求解器。linear_solver 若传入，约定接收 A,F，返回同形状的有限数值向量。

solve_steady(t=0)：在指定参数时刻做稳态求解，不等于把含时方程走一步。
solve_time(end_time,steps,scheme="bdf2",output=None)：从零时刻初值推进；output 指定目录时输出时序文件。
assemble(t)：返回尚待边界处理的 A,M,F。
errors(t=0)：返回 L² 误差和 H¹ 半范数误差。
box_mesh(pde,n)：按模型维数生成盒形单纯形网格。

上述方法均属于项目。FEALPy 的原生接口与源码阅读见 [FEALPy 学习入口](../03_FEALPy学习/00_库与项目的边界.md)。

## 14. 小练习与参考解释

1. 把最小例子的 n 改为 4，p 保持 1。预期五个自由度，而不是四个。先打印坐标和值，再谈精度。
2. n=2、p=2 的一维空间有五个自由度；这是增加边中点，不是把网格自动改成四段。
3. 让 end_time=1、steps=5，时间步是 0.2。只把 steps 改为 10，最终时刻不变，步长减半。
4. 两种物质、每种 5 个自由度，反应系数 C 是 2×2，而反应离散矩阵 R 是 10×10。
5. 用第 12 节与第 3 节分别求相同稳态问题，比较系数。一个不知道真解，一个知道真解，但它们的 source 和 boundary 相同，因此应得到相同离散解。
6. 阅读一次 ScalarDiffusionIntegrator 的源码，指出哪部分在积分点求值、哪部分形成局部矩阵。不要把项目 assemble 的物质循环说成 FEALPy 积分器内部行为。

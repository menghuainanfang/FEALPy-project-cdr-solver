# 分级实践与参考答案

## A 入门：先预测，再运行

问题一：d u_t+2u=10，u=1、d=2 时 u_t 是多少？
答案：(10−2)/2=4。u 在增长；左侧有 +2u 并不表示反应在增加它。

问题二：把 [0,1] 分成两段，P1 有几个全局自由度？两物质呢？
答案：3 个；6 个。单元数、自由度数、物质数是不同量。

问题三：solve_time(0.8,4) 走到哪些时刻？
答案：0.2、0.4、0.6、0.8，从 t=0 的初值开始。

## B 基础：完成可核对的小程序

运行 example_minimal.py，把 n 从 2 改成 4。记录节点坐标、系数长度。预期长度从 3 变 5。再把 p 改成 2，长度变成 9。不能仅以“没报错”作为完成证据。

在另一份练习文件里使用程序讲义第 12 节的无真解数据，与制造解版本比较同一网格上的解。它们输入的实际方程一致，节点系数应一致；无真解版本不调用 errors。

打印 initial(points) 与 initial(points).T.reshape(-1)，说明二维表的行列各是什么。两物质两节点 [[10,20],[11,21]] 应排成 [10,11,20,21]，不是 [10,20,11,21]。

## C 进阶：确认公式而不是背调用

从一个空间反应项 C₁₂∫φⱼφᵢ 出发，指出它进入哪一块：第 1 个物质方程行、第 2 个物质未知量列。代码下标从 0 开始，对应 forms[0][1]。修改这项会影响联立结果，不只影响一个独立后处理数值。

用后向欧拉法计算 U̇+2U=0，U⁰=1、dt=0.1。得到 (1+0.2)U¹=1，U¹=5/6。第二步若用 BDF2，(1.5+0.2)U²=2×(5/6)−0.5，得到 U²=35/51。明确旧值、上上层值的位置。

运行 verify_vector.py，读 spatial.csv 中固定维数、固定 p、固定稳定化的三行。网格加密一倍后 P1 的 L² 误差约缩小四倍、P2 约八倍，是光滑制造解下的预期；不要把它当成任意不光滑问题的保证。

## D 综合：能够解释一个改变

仅改变 n 或时间步数，分别观察空间或时间误差。一次同时改多个因素就难以解释结果。然后比较强对流算例的 Galerkin 与 SUPG：说明过冲/欠冲、边界层分辨率和 L² 误差不是同一个指标。

最后口述：我的输入来自什么，FEALPy 做了什么，项目代码增加了什么，我用哪些证据相信输出。能回答这四点，再进入自定义数据类和 SUPG 局部数组实现。

遇到失败先缩回一维小网格，打印 shape、系数和边界；保留失败证据并找出哪条数据约定被破坏，不随意删掉验证断言。

# FEALPy 学习入口

先读主程序讲义，再按本文件夹的 01→02→03 顺序阅读。这里拆解 FEALPy 本身，项目源码只用作调用者对照。固定交付依赖为 FEALPy 3.4.0；本地开发仓库可能与已发布版本不同，查看源码时先确认导入位置。

```python
import fealpy

print(fealpy.__file__)
print(inspect.getfile(ScalarDiffusionIntegrator))
```

不要把电脑上的绝对路径抄成别人必须具有的路径。以下路径都从 FEALPy 仓库根目录算起。

| 库模块 | 本项目使用什么 | 不负责什么 |
|---|---|---|
| fealpy/backend | backend_manager 数组运算 | 不自动决定本项目支持 GPU |
| fealpy/mesh | 区间、三角形、四面体网格 | 不知道具体反应方程 |
| fealpy/functionspace | 基函数、自由度、有限元函数 | 不自动推导 CDR 模型 |
| fealpy/fem | 积分器、装配、边界、分块 | 不自动决定时间推进和物质耦合 |
| fealpy/sparse、fealpy/solver | 稀疏存储和线性求解入口 | 不替代 PDE 建模与误差验证 |

项目 cdr/pde.py 提供数据；cdr/solver.py 组织这些库对象；cdr/stabilization.py 计算扩展局部数组；cdr/cases.py 提供测试模型。学习库的风格，不等于复制整个库进项目。

本夹的源码导读根据本机 FEALPy 实际文件检查；只讨论当前项目用到的路径。不同版本内部分派和缓存机制可能不同，公共调用与测试结果应优先于记忆中的行号。

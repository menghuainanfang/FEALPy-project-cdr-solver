## 新项目的 README

每个项目说明应包含：研究或练习目标、使用材料与依赖、目录和运行入口、已有产出、当前进展及下一步。项目命名使用简短主题，例如 `poisson-fem-practice/`；完成一个独立练习也保存在自己的目录中。

项目自己的数据和结果放在项目内。与移动网格主线建立联系时，在项目 README 中链接对应的主线文档。

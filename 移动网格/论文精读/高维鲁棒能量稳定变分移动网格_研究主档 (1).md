## 1. 先把题目拆开

| 词语 | 启动阶段的理解 | 要落实为哪些可检查对象 |
| --- | --- | --- |
| 移动网格 | 通过移动节点改善离散点分布，典型r自适应阶段保持连接关系 | 节点坐标、单元连接、边界约束、网格速度 |
| 变分 | 用泛函或离散目标函数衡量网格质量，通过优化或梯度流产生网格 | 能量公式、未知量、梯度、可行域 |
| 能量稳定 | 离散方法保留某种能量估计 | 原始或修正能量；连续、半离散或全离散；步长条件 |
| 鲁棒 | 在一组明确困难条件下，仍能稳定地产生合格结果 | 不翻转、失败率、最小体积、误差、耗时、参数敏感性 |
| 高维 | 暂按从二维到三维规划，等待导师确认 | 维数d、节点数N、维数相关常数和成本 |
| 应用 | 网格最终改善一个具体PDE问题的求解 | 同等精度成本、同等成本误差、守恒或能量性质 |

特别区分：大规模网格有很多自由度，不等于PDE空间维数高。三维四面体计算也不能证明方法适合十维或百维PDE。如果导师指d≥4，需要重新讨论表示方式、复杂度与可实施的验证目标。

### 1.1 两种能量不能混淆

**网格能量**写成\(I_h(X;M)\)：\(X\)是网格自由节点坐标，\(M\)是度量张量。它衡量节点分布、单元形状与目标度量的匹配。

**物理能量**写成\(E_h(U,X)\)：\(U\)是PDE离散解。例如扩散问题可能有某种能量衰减，Hamilton系统则可能要求能量守恒。

网格能量下降，不自动推出物理能量下降；重新插值、投影、网格更新和时间推进都可能改变物理能量。对有源项或边界输入的问题，合理目标也可能是带输入项的能量估计，而非单调下降。

因此，本项目暂以“固定度量下网格算法的稳定性”为第一层，再讨论PDE耦合。若导师的核心目标是物理能量稳定，应据此调整研究主线。

### 1.2 与导师核对的六个问题

1. “高维”主要是二维/三维，还是一般d维甚至更高维？
2. “能量”是网格泛函、PDE能量，还是二者都要控制？目标是原始能量还是可接受修正能量？
3. 有无指定的基础论文、已有算法、组内代码或尚未解决的问题？
4. “鲁棒”最想解决哪种失效：网格翻转、大步长失败、强各向异性、复杂边界，还是线性系统病态？

这些问题不妨碍现在学习和做最小算例；它们用于防止两三个月后才发现选错主线。

## 2. 一个需要真正掌握的数学骨架

以下是固定度量、固定连接关系、已消去固定边界自由度后的示意模型，不是对任意移动网格方法的完整描述。

设\(X\in\mathbb R^{dN_f}\)，\(I_h(X)\)可微，\(B(X)\)对称正定，考虑

\[
\dot X=-\frac1\tau B(X)\nabla I_h(X),\qquad \tau>0.
\]

由链式法则，沿可行解轨道

\[
\frac{dI_h}{dt}=\nabla I_h^T\dot X
=-\frac1\tau\nabla I_h^TB(X)\nabla I_h\le0.
\]

这说明连续伪时间系统能量下降。**它没有证明某个程序的离散迭代也下降。**它也没有单独证明网格永远不退化。

以\(B=I\)为例，显式更新\(X^{n+1}=X^n-\eta\nabla I_h(X^n)\)。若梯度在相关线段邻域内L-Lipschitz，则

\[
I_h(X^{n+1})\le I_h(X^n)
-\eta(1-L\eta/2)\|\nabla I_h(X^n)\|^2.
\]

小步长可能保下降，但网格接近退化时梯度常数可能恶化，而且上述估计需要更新留在函数定义和可行区域内。能量检查与几何可行性检查因此要同时做。

对于随解更新的度量\(M\)，不同外迭代实际使用不同的目标函数。冻结\(M\)的内迭代能量下降，不等于跨越度量更新后同一条曲线仍应下降。比较能量前必须固定定义、归一化和度量状态。

Huang–Kamenski的非奇异性工作[2]给出带条件的理论：初始网格非奇异、泛函满足相应强制性等假设时，半离散网格不退化；全离散结论还涉及时间步长和能量单调格式。应读清定理条件，不能简化为“任意MMPDE和任意步长都不会翻转”。

**第一项理论能力目标：**不看笔记推导上面两个能量关系，并指出分别用了哪些假设。随后再精读[2]如何把能量控制转化为单元几何下界。

## 6. 建议的最小实验序列

### E0：一维等分布，理解网格为什么会聚集

在\([0,1]\)取正监控函数\(\rho(x)=1+\alpha\exp[-\beta(x-1/2)^2]\)，先取\(\alpha=9,\beta=100\)。定义

\[
F(x)=\frac{\int_0^x\rho(s)\,ds}{\int_0^1\rho(s)\,ds},\qquad
x_i=F^{-1}(i/N),\ i=0,\ldots,N.
\]

用数值积分和单调反求生成节点。检查节点严格递增、端点固定、每段监控质量近似相同。对一个峰值函数比较均匀节点和上述节点的分段线性插值误差。这是概念实验，不声称监控函数最优，也不把它当成已经实现了变分移动网格。

### E1：二维纯网格实验

单位正方形、三角形网格、固定边界、冻结\(M=I\)。从轻微扰动且全部正定向的初始网格开始。先复现[1]/MMPDElab中对应实现，再选定一个明确的物理坐标或计算坐标版本自行实现。

不要混用\(X\)和\(\xi\)两种未知量的梯度公式；初期沿用先前精读笔记的简单泛函路线，但不得对Winslow泛函自动套用其他泛函的非奇异性结论。

每步记录\(I_h\)、\(\min_K\det F'_K\)、最小面积、最大单元映射条件数、梯度范数、步长、回溯次数。行列式需相对统一定向的参考单元计算。能量下降但单元翻转，应判为失败。

### E2：冻结各向异性度量

构造\(M=R\operatorname{diag}(\lambda_1,\lambda_2)R^T\)，扫描特征值比，例如1、10、100、1000。为避免把密度变化和各向异性混合，可先令\(\lambda_1=\sqrt\kappa,\lambda_2=1/\sqrt\kappa\)，保持行列式为1。再单独研究空间变化度量和密度变化。

比较无回溯小步长、带下降及几何检查的回溯、作者求解器基准。记录强度增加后的失败率与成本。某个阈值失败是研究线索，不急于把阈值调小后删掉失败记录。

### E3：Poisson应用闭环

先在单位正方形上取\(u=\sin(\pi x)\sin(\pi y)\)，\(-\Delta u=2\pi^2u\)，零Dirichlet边界，验证固定网格P1有限元。在标准正则性与形状正则网格条件下，预期\(H^1\)误差约一阶、\(L^2\)误差约二阶；它是实现核验例子，不一定能显示自适应优势。

再选有局部窄峰或陡变带的光滑制造解，解析求\(f=-\Delta u\)，使用相应精确边界值。统一求解器容差和积分精度，比较均匀与自适应网格的误差—自由度、误差—总耗时。总耗时包含度量构造、移动网格、数据传递与PDE求解。

### E4：时间相关应用与三维

先做热方程，再按导师要求考虑Allen–Cahn或其他模型。Poisson用于验证基础和效率，不能单凭它宣称物理时间能量稳定。移动网格上需处理网格速度、解转移和边界；若采用ALE或重映射路线，应检查常数解保持及相应几何守恒要求。

二维闭环可信后再将局部单元几何扩展到四面体，控制节点规模和内存。三维重点记录有向体积、近退化单元和求解成本，不能只交一张漂亮的三维图。

| 步长与可行性 | 在保证能量下降和单元可行的情况下，能否减少拒绝步和总耗时？ | 单纯加回溯是标准做法；必须与已有方法比较 |
| 预条件或缩放 | 强各向异性下，哪些缩放降低迭代成本而不破坏目标性质？ | 迭代数减少不等于总耗时减少 |
| 原始能量稳定的时间推进 | 离散梯度或变分时间步能否用于给定网格泛函？ | 非线性求解误差、存在性、可行性不能省略 |
| 度量正则化 | 如何平衡误差适应性、条件数和网格质量？ | 更平滑更稳定可能只是放弃了解分辨率 |
| PDE与网格耦合 | 网格重分布后，怎样控制物理能量与传递误差？ | 网格能量下降不能作为物理稳定性的替代 |

建议第一候选是“指定泛函上的保可行下降策略与鲁棒性评估”，因为与当前能力成长衔接较短。若导师已有新的能量稳定格式，则优先复现其方法，不自行另开主线。

关于SAV/IEQ：它们是值得学习的结构保持工具，但“加一个辅助变量”不会自动解决网格正定向、退化奇异性或原始能量下降。必须核对适用能量结构和到底控制哪一种离散能量。[5]是方法背景，非本课题可直接套用的现成答案。

## 10. AI怎样真正帮助研究

把AI用于“解释—实现—核验”的小循环；你负责数学模型、假设、实验设计和结论的最终判断。

| 场景 | 合适的交付要求 | 你需要自己完成的核验 |
| --- | --- | --- |
| 读论文 | 按页码解释一条公式，列未知量和假设 | 回原文确认符号、条件与结论 |
| 推导 | 分步求矩阵微分、检查维度、尝试反例 | 手算小矩阵；不能以两个AI意见一致代替证明 |
| 编程 | 一次实现一个有输入输出和验收标准的函数 | 几何恒等式、方向差分、制造解或参考实现核对 |
| 实验 | 生成参数扫描、表格和图 | 检查配置、原始数据、失败运行、总成本统计 |
| 写作 | 根据已有结果润色结构和语言 | 不生成未做的实验、未证的定理或假引用 |

每个核心模块建立三点对应：论文公式/自推公式 → 代码位置 → 验证证据。对能量梯度，可比较解析梯度、自动微分和中心方向差分；三者共享同一错误能量表达式仍可能一致，所以还要手算最小单元。

请求AI推导时，应明确“冻结M还是连同M对X求导”。许多实现会冻结监控量；若AI自动微分了所有依赖，可能悄悄换成另一算法。

能力保护规则：每完成一个AI辅助模块，自己解释输入、输出、公式、复杂度和一个失败情形；挑一个小例子独立复现。AI能运行代码不等于你能答辩。

若交给本机编程助手，任务说明需包含：先读项目约定与环境；不覆盖已有文件；先做二维单元几何和梯度核对；使用float64；分别报告测试通过、失败和未执行项；未经结果验证不宣称稳定或收敛。当前无须搭建复杂多智能体系统。

## 11. 实验与证据规范

每次运行至少记录：实验ID、日期、代码提交、环境、维数、节点/单元数、初始网格、随机种子、度量定义及参数、泛函参数、边界处理、时间步/线搜索参数、求解容差、停止原因、机器信息、耗时范围与失败信息。

最小结果表应包括：网格能量及其定义、最小有向单元体积、网格质量、PDE误差（适用时）、总耗时与各部分耗时、迭代和拒绝步次数、失败率。

公平对比先固定节点数和相同初始条件，再做同等误差的成本比较。随机扰动研究要使用一组固定种子并报告分布，不只选择成功的一次。阈值和浮点容差应说明与尺度的关系，不能用大容差掩盖真实能量增长。

证据标签统一为：**已证明 / 原文定理 / 已复现实验 / 本轮观察 / 待验证猜想**。能量图下降只是数值证据；全离散能量不等式、非奇异性、收敛性和误差阶是不同的命题。

## 13. v0.2：具体研究方向与双节点成果计划

### 13.1 推荐做成什么样

建议的内部工作标题：**基于FEALPy的二维/三维变分移动网格：能量下降、单元非退化与计算效率研究**。这是导师原题下的工作范围，不自行改掉正式题目。

推荐组合为：**二维做深，三维验证；维数统一的公式与代码组织作为设计目标；固定度量下网格能量稳定作为第一理论目标；一个PDE作为应用闭环。**暂不承诺任意高维、任意步长、任意初始网格、网格与物理能量同时稳定。

适合集中研究的问题是：对一个明确的变分网格泛函，能否设计或改进更新策略，在强各向异性和接近退化但仍可行的初始网格下，以可接受成本保持网格能量下降和正定向，并在PDE误差—成本比较中体现价值？

算法候选从基线失效中选择：步长控制、预条件、可行域保护、时间离散四选一，不同时铺开。标准回溯本身不算新方法；必须说明已有方法缺口、具体改动、适用条件和收益。基准若没有明显失效，先做性能与敏感性分析，不人为制造“创新”。

理论目标应分层：先完整重现既有下降证明；再争取证明自己具体改动下的充分下降或步长接受性质。若讨论单元非退化，还需核对泛函强制性、度量有界性、边界条件等。只检查新旧端点正定向，不能自动推出整个节点运动路径均不退化；局部Jacobian正也不自动排除全局网格重叠。采用哪一种几何保证，应明确写出。

| 光滑制造解Poisson | 第一核验，确保装配与误差正确 | 不是物理时间能量稳定证据 |
| 局部窄峰/陡变带插值与Poisson | 展示网格适应性及精度—成本 | 不能只比较误差、不算移动成本 |
| FEALPy已有黏性Burgers算例 | 优先考察的时间相关应用，便于组内复现 | 需区分空间稳定性、时间步限制与网格失效 |
| 热方程或Allen–Cahn | 导师若明确要求物理能量稳定，再选其一 | 有边界输入时不应直接要求总能量单调下降 |

到2027年6月，不要求上述应用全做。目标为一条完整验证链和一个主要应用。避免因为展示面广而同时承担相场、流体、神经网络等多条路线。

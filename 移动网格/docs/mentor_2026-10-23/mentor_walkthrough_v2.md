# 三分钟演示：网格为什么随时间移动

打开[网格随时间演化](http://localhost:8765/results/mentor_2026-10-23/p2_v2/index.html)，默认选择解析移动界面、60个物理步。

**0:00—0:40：先看发生了什么。**

页首说明这是解析时变目标驱动的网格演示，没有求解非线性PDE。点击播放，物理时间从0推进至1.2，包含60次实际更新和61个时间节点。界面中心在x=0.32至0.68间运动，网格沿用上一时刻的形状并跟随目标；灰线可以切换为上一物理时刻或固定基线。拖到书签t=0.30、0.60、0.90观察界面与网格的相对位置。

**0:40—1:30：展开一次物理步。**

展开算法模式，选择物理步n=1、耦合轮k=1。t保持0.02，滑动内层j；这里只有网格伪时间s变化。计算网格ξ在冻结物理网格和M下优化，右图是实际映射结果。残量曲线有实际阈值；窗口位移、能量变化率及连续计数各自检查。BDF接受步不是物理步，也不是播放器帧。

切换同一n中的其他k，看映射后的物理网格如何成为下一轮输入。只有网格与度量变化连续两轮都足够小，解析案例的外层才结束；内层先收敛不代表外层已经完成。非关键物理步也保存全部诊断，中间坐标未保存时会明确提示。

**1:30—2:20：切到真正的数值PDE。**

选择“数值Burgers”。此处内部自由度来自P1有限元、后向Euler和Picard求解；解析解仅提供初边值、源项和误差基准。M来自当前数值解梯度。第一轮k=1的场一致性没有前一轮参照，因此显示“尚未检查”；这与已检查但未达标、达到外层预算、PDE求解失败是不同状态。

本例已实际推进60步。物理步n、耦合k和网格j三个控件独立；每层都显示为什么继续或停止。时间t、伪时间s和实测墙钟秒不是同一个量，播放速度也不参与求解。

**2:20—3:00：看验证与结论边界。**

展开来源与验证，查看每步数据和重跑命令。相邻物理步的网格继承差为0，固定网格时间加密的节点自差比约1.956。t=0.2、nx=8时，移动网格PDE L²误差约0.03584，固定基线约0.01731；当前移动网格并没有提高这一Burgers算例的精度。P1转移不严格守恒，质量差另行记录。

最后切到静态输入：物理步始终0，t保持0，只展示网格优化。这说明演示区分了真实时间更新、网格优化和PDE数值求解。回到解析案例可选择100步深化版到t=2.0；不是用更多动画帧拉长三步数据。

## 1. 首要交付：术语与计数审计

做一张机器可核对的字段词典，UI 鼠标提示和 `docs` 共用，至少包含：

| 变量 | UI 推荐中文名 | 单位/意义 | 与其他数字的关系 |
| --- | --- | --- | --- |
| `physical_time` / `t` | 物理时间 | 真实 PDE 演化时间 | 与网格伪时间独立 |
| `physical_step_index` / `n` | 物理时间步 | t_n→t_{n+1}，从 0 或1如何计数须明确 | 不等于物理帧数 |
| `outer_iteration` / `k` | 物理解—网格耦合轮次 | 单个物理时间步内重复求解/重分布次数 | 不等于物理步 n |
| `mesh_pseudo_time` / `s` | 网格伪时间 | 网格 ODE 内部的演化变量，可能到上限 | 不是CPU秒，也不是物理时间 |
| `accepted_bdf_steps` / `j` | BDF已接受内部步 | 数值积分器成功推进了几步 | 可远大/小于展示帧 |
| `rejected_bdf_attempts` | BDF拒绝尝试数 | 若内部API无法准确提供，则标记“未提供”而非猜测 | 不等于accepted steps |
| `saved_frames` | 可播放保存帧数 | 渲染/输出采样密度（如61帧） | 改变帧数不应改变底层方程 |
| `display_frame_index` | 当前第几帧 | 播放定位，给出0/1-based定义 | 不等于迭代次数 |
| `nfev, njev, nlu` | RHS调用/Jacobian计算/LU分解数 | 数值求解器统计，按库的实际定义 | 绝不能统一叫“迭代次数” |
| `pseudo_step_size` | BDF内部接受步长 Δs | s_{j+1}-s_j | 与输出采样间隔不同 |
| `output_sample_dt` | 相邻展示帧间隔 | 由可视化采样决定 | 不用于判断真实积分步长 |

| `mesh_residual_rms` | 网格平衡残量 RMS | 明确自由度、缩放、量纲 | 不一定等于原始速度范数 |

## 2. 单独设计收敛判据，不再让“达到时间上限”混同“converged”

必须建立独立的 `MeshConvergenceMonitor` 或等价纯函数模块，接受一个**BDF已接受的候选状态**，输出 `residual, displacement, energy_change, geometry_valid, consecutive_success, stop_reason`。诊断逻辑与绘图层隔离，所有阈值配置化并写入 JSON。

- **主判据：网格平衡残量**。优先核对 FEALPy 离散网格梯度/平衡装配、边界投影、节点度量缩放。若监控投影后的伪时间速度 `v=P(-gradient(I))`，必须明确 τ/预条件尺度；在统一无量纲化后报告 `r_RMS=sqrt(sum_{i in free}|r_i|²/N_free)` 及所用 `r_ref`，并解释对应的是梯度残量还是速度残量。不能仅凭速度很小便称“能量极小值”。
- **辅助判据：节点变化**，用 `Δx/h_local`、`Δξ/h_ref` 或等价无量纲量；**必须防止因积分器步长极小造成假收敛**。可按固定伪时间窗口或固定数量接受步比较，而非只看当前自适应 Δs。详述参考网格尺度。
- **辅助判据：冻结度量能量相对变化**，例如 `|I_j-I_previous|/max(|I_previous|,I_scale)`；如果更新物理网格或 M，则能量函数本身改变，需分 epoch 绘图与比较，**跨 epoch 能量值不能无条件解释成单调下降**。
- **硬约束：最小正有向面积/单元质量、边界投影和角点规则**。违反约束不能宣布收敛，即使残量已经下降。
- **状态机明确**：`converged` 仅在符合收敛条件且数值求解成功时；`pseudo_time_cap` 表示到达上限但未过收敛阈值；`max_accepted_steps`、`solver_failure`、`invalid_mesh`、`outer_not_converged`（由P2管理）单独命名。若同一步既到达 t_cap 又满足阈值，要保留两个布尔事实 `criterion_met` 与 `cap_reached`，报告策略优先级，不能只留含糊 stop_reason。
- **防误判**：最小伪时间或合理诊断窗口、连续成功计数（如连续3–5个内部接受检查，默认作为可调示例，而非理论阈值）、绝对/相对残量阈值；零运动初始状态和小步长卡顿要有专项测试。
- 设计 `mesh_status` 与 `solver_status` 双层状态：`solver_status=success` 只能说明积分器数值前进成功，`mesh_status=converged` 才说明满足网格停止条件；`PDE_status`另属于P2。
- 输出上一次未收敛原因：如 `r_RMS=7e-5 > tol=1e-6`、`未达到连续成功次数`、`最小有向面积不合法`，不要只显示“否”。

可配置阈值应先用于复现旧版并观测诊断，再选择有意义的尺度而非调宽容差使曲线看起来“收敛”。保留 `criterion_version`/公式与量纲。

输出表至少包括：`scenario, nx, threshold, rtol, atol, pseudo_time_cap, first_converged_s, final_s, stop_reason, cap_reached, display_frame_count, bdf_accepted_steps, nfev, njev, nlu, min_signed_area, residual_initial/final, energy_initial/final, wall_seconds`。

## 4. 网页必须拥有“收敛判据说明”专门面板

所有重点实验（静态 E 和动态 P2）使用统一词典、统一状态：
- 独立区域「**这个网格算收敛了吗？**」：显示 `网格残量: 当前值/阈值`、`位移判据: 当前值/阈值/采样窗口`、`能量变化: 当前值/参考规模`、`几何合法: 是/否`、`连续达标次数: m/M`、`最终停止原因`。每项旁边有问号说明精确定义，标明主判据/辅助指标。
- 三张可交互曲线：`r_RMS 对 s`（阈值水平线、首次达标垂线）；`I_h 对 s`（清楚注明 frozen metric epoch）；`Δs_BDF 对接受步 j`。必要时补画最小 signed area。
- 单独「**数字是什么意思？**」面板，表格列出 `展示帧 61`、`BDF接受步 111`、`RHS调用 57` **仅当真实运行数据确实如此，否则按实际数据动态展示**，且说明这些计数可能交叉、大小没有固定数学排序。
- 计数统一用 `当前序号/总数` 加名称与说明：例如“可视化 第61/61帧”“BDF接受步 第111/111步”；不显示没有定义的 `迭代=61`。
- 伪时间与物理时间分开，不使用“伪时间5.0s”来暗示 SI 秒；可标为 `网格伪时间 s=5.000`、附注“网格演化参数，非真实运行耗时”。
- 不只显示终值，还在时间轴当前位置同步当前残量、判断条件和进度：用户拖动轨迹应能知道为什么“当时没停、后来停了”。
- 设计一个“**3分钟看懂收敛**”分步讲解模式：初始残量→逐步下降→首次满足阈值→连续达标→停止；对未收敛案例显示真实失败/上限，不假装完成。

- 固定数值配置更改展示帧数不会改变“是否收敛”的判据定义；
- `cap_reached=true` 且阈值未达必须标为未收敛；
- s刚好上限达阈值时保留两项事实；
- 固定边界/滑动边界自由度口径正确；
- 假收敛案例（Δs极小、速度尺度过小、几何翻转）被拒绝；
- 能量缩放/度量epoch切换时不误判跨epoch单调；
- 传统 E 页面可打开，旧 JSON 至少有向后兼容路径；
- 生成中文解释不引用虚构数值，失败也展示日志。

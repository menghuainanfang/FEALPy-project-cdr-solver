【为什么学】本周导师布置：调研 Allen–Cahn（AC）、Cahn–Hilliard（CH）、黏性 Burgers 方程及它们与 Navier–Stokes（NS）之间的真实联系；尝试在一个固定网格上数值求解至少一个非线性 PDE。我的毕业研究仍以导师2026年迹—对数变分移动网格方法的三维实现为长期目标，但本周先学习 PDE 求解，不接移动网格三重循环。

【先澄清概念】Burgers 是带非线性对流的黏性模型、与 NS 的对流项有联系，却没有自动包含 NS 的不可压缩约束及压力；标准 AC 是非守恒 L² 梯度流；标准 CH 是守恒 H⁻¹ 梯度流/四阶演化 PDE，两者均可与 NS 耦合构成扩散界面两相流模型，但它们不是 NS 方程的不同名字。严格区分普通 AC、保守 AC、CH、Burgers、NS 和耦合 AC–NS / CH–NS，绝不混称。讲清相场物理意义、适用背景及参数的量纲。

【教学顺序】先给三种 PDE 的学习地图和本周最小产物，然后从 Burgers 开始：
1. 一维黏性 Burgers：u_t+u u_x=νu_xx+f。解释非线性、对流/扩散、初边值条件；推导弱形式，解释有限元质量、扩散、非线性对流项；从固定网格 P1 和后向Euler/半隐式开始，辨析 Picard、Newton 和显式处理所对应的离散方程。1D 可以作教学台阶，但必须设计向二维三角网格的可运行数值实验。
2. 标准 AC：以 E(φ)=∫Ω[ε|∇φ|²/2+F(φ)/ε] dx，F(φ)=(φ²−1)²/4 为一致约定，μ=−εΔφ+F'(φ)/ε，φ_t=−m μ。推导弱形式及 dE/dt=−m∫μ² dx（适用边界条件下），讨论一般不守恒质量与曲率驱动界面演化。讲清线性化和能量数值诊断，别自动宣称某时间格式能量稳定。
3. 标准 CH：使用同一 E，φ_t=∇·(m∇μ)，μ=−εΔφ+F'(φ)/ε。导出两个二阶方程的混合弱形式与 P1–P1 离散，验证无通量边界时质量守恒、能量耗散 dE/dt=−∫m|∇μ|² dx。理解两个未知量、块矩阵和非线性求解。
4. 不可压缩 NS：u_t+(u·∇)u+∇p−νΔu=f、∇·u=0（常密度示意，说明假设）。解释与 Burgers 的共同项、不同的压力/散度约束；用 CH–NS 的输运项和力耦合说明关系，但本周不要强行实现完整 NS 或 CH–NS。
5. 通过方程对照表，总结未知量、方程阶数、非线性项、物理守恒、耗散机制、边界条件、有限元空间和经典验证指标。

# CDR 多维含时求解器

方程为 d u_t − div(a grad u) + b·grad u + c u = f。稳态调用 `solve()`；含时调用 `solve_time(end_time, steps)`。

## 运行

本机运行全部验证和生成报告：

```powershell
python verify_extension.py
```

在其他机器安装依赖后，在解压目录运行：

```text
python -m pip install -r requirements_extension.txt
python verify_extension.py
python example_extension.py
```

## 修改题目

`example_extension.py` 提供不依赖精确解的二维例子。空间坐标按 `x0`、`x1`、`x2` 命名，时间为 `t`。系数可以是数字、字符串或对应的 SymPy 表达式，例如 `d='1+x0+t'`。b 是分量列表，长度与维数一致。

`CDRData` 统一接收系数、源项 `source`、边界值 `boundary` 和初值 `initial`。制造解实验可以提供 `exact`，由类计算源项和精确梯度；实际问题直接提供 source、boundary 和 initial。精确解不是求解器的必需输入。

默认区域为单位盒，`box=[xmin,xmax,ymin,ymax,...]` 可修改范围。`box_mesh(pde,n)` 每个坐标方向划分 n 段。`LagrangeFESpace(mesh,p=1)` 的 p 可取 1 或 2。

含时求解增加 `output='my_results'` 会输出每一步的 VTU 和记录实际时间的 PVD。用 ParaView 打开 PVD，点击 Apply，选择颜色字段 u，再播放时间序列。

项目中的 `pde` 是本项目的 PDE 数据包。求解器调用 FEALPy 的空间、积分器、边界条件和稀疏求解接口；没有注册为 FEALPy 官方模型。

验证报告、图片和原始数据见 `多维含时求解器_任务报告.md` 与 `results_extension`。

| **Featflow** | FEM | 德国多特蒙德大学 CFD 代码 | 只有 Navier-Stokes 的 [DFG 绕柱流基准](https://wwwold.mathematik.tu-dortmund.de/~featflow/en/benchmarks/ff_benchmarks.html)，**无对流扩散基准** |

### 2.3 商业软件

- **COMSOL Multiphysics**：系数形式 PDE 界面——用户在 GUI 里直接填 $c\nabla u$、$\boldsymbol\beta\cdot\nabla u$、$au$ 三个项的系数（就是本任务的 a、b、c），支持任意变系数表达式。商业软件的做法与本任务方程一一对应。
- **ANSYS Fluent**：UDS（用户自定义标量）输运方程，同样是对流-扩散形式。

**小结**：CDR 方程是计算数学/CFD 的「标准问题」，各软件都有对应模块；但**以「变多项式系数 + 教学验证 + 全流程交付」为目标的轻量 Python FEM 求解器**，没有直接现成的开源成品——这正是本任务要动手实现的原因。最接近的参考物是 FiPy（三项组合 API 设计）与 scikit-fem（Python FEM 教学例）。

## 4. 数值方法学调研（本任务要用的配套模块）

### 4.1 制造解（MMS）——数值正确性验证的标准方法

给定精确解 $u_{ex}$ → 符号/手工计算 $f=-(au')'+bu'+cu$ 与边界值 → 解数值方程 → 比对误差。这是计算科学界验证代码正确性的标准做法（Roache 的「方法制造解」方法论，也是各库教程通用手段）。**要点**：$u_{ex}$ 应选非多项式（sin/cos/exp 组合），否则 P1/P2 元可能恰好精确复现，验证失效。

### 4.2 收敛阶验证

理论阶：P1 元 L2 阶 2、H1 阶 1；P2 元 L2 阶 3、H1 阶 2。做法：网格逐级加密（h→h/2），`order = log2(e_h / e_{h/2})`，实测阶逼近理论阶即判定实现正确。可输出 log-log 收敛图（理论斜率参考线对照）。

### 4.3 对流占优与稳定化（何时才需要）

- 判别量：**Péclet 数** $Pe = |b|h/(2a)$（单元尺度）。$Pe\gtrsim1$ 时标准 Galerkin 出现伪振荡（FreeFEM 论坛与 scikit-fem 文档均有实例）。
- 对策梯度：人工扩散（迎风）→ SUPG/流线扩散 → DG。
- 本任务：a、b、c 为多项式且不复杂，**设计算例时保持 a 不太小即可避开**；报告中说明该边界，作为后续进阶方向（FEALPy 的 parabolic/level-set model 有 SUPG 参考实现）。

### 4.4 符号推导辅助（sympy）

f 与边界值的推导手工易错（多项式 a、b、c 的求导与组合），用 **sympy** 自动生成 f 表达式（再 lambdify 传入求解器），保证「右端项」与「精确解」严格配套——这是制造解管线的关键一环。

### 4.5 边界条件

- 全 Dirichlet：`DirichletBC(space, gd=u_exact)` 一步完成（矩阵修正 + 右端修正）。
- Neumann/Robin（若任务要求）：弱形式多一项边界积分，FEALPy 有 `ScalarRobinBCIntegrator`。

### 4.6 可视化

matplotlib（中文微软雅黑已配置）：1D 解曲线对比图、2D 解曲面（`mesh` + 等高线）、误差分布云图、log-log 收敛阶图、a/b/c 系数场图。

## 6. 推荐实施方案概要

1. **1D 主体 + 2D 推广**：IntervalMesh 完成全部验证管线（快速、可手算对照），TriangleMesh 做展示算例。
2. **模块化求解器类**：`CdrSolver1D(a, b, c, f, gd, mesh, p)` —— 输入系数多项式 + 网格 + 元次数，输出 uh、误差、收敛阶；接口设计借鉴 FiPy 的「三项自由组合」思路。
3. **验证管线**：sympy 推导 f → 求解 → mesh.error → 逐级加密 → 收敛阶表 + log-log 图 → 与理论阶比对。
4. **算例设计**：2~3 组非平凡多项式系数（保证 a>0, c≥0）+ 1 组退化 Poisson 对照。
5. **文档链**：任务了解 → 调研报告（本文）→ 设计方案 → 程序 + 算例 + 图片（学习笔记按交付规范整理）。

# FEALPy 兼容性说明

扩展模块通过安装版 FEALPy 3.4.0 和本机源码版 v3.4.1-47-ge033533bd-dirty 的针对性运行验证。两套环境均覆盖 1/2/3 维、P1/P2、时间推进和 VTU 数值读取。

## 风格与接口

PDE 数据集中在 `pde/CDRData`，提供 domain、solution、gradient、source、dirichlet 及 a/b/c/d 对应系数函数。函数使用 cartesian 坐标标记，标量返回 points.shape[:-1]，向量增加末尾空间维数。SymPy 符号按坐标和时间名称统一，支持带 real=True 等假设的表达式。

求解器使用 LagrangeFESpace、BilinearForm、LinearForm、ScalarDiffusionIntegrator、ScalarConvectionIntegrator、ScalarMassIntegrator、ScalarSourceIntegrator、DirichletBC 和 FEALPy spsolve。未调用 fealpy.old。积分器初始化、系数检查与线性系统组装分别有独立方法，线性求解器在初始化时选择。对流使矩阵一般非对称，默认采用稀疏直接求解。

这一结构吸收了 FEALPy PDE 数据类和有限元装配的编程方式。符号函数在实例初始化时编译；数值求值使用 NumPy。项目 pde 目录属于应用代码，并未向 FEALPy 的 pde 或 fem 目录注册模型。

## 共同使用

- 导入核心模块保持当前 FEALPy 后端、sys.path 和 fealpy.fem 的公共对象不变。
- 求解和导出保持调用者的节点、单元、已有 nodedata 字段及原有 u 数组不变。VTU 导出在单独的网格对象上附加顶点数据，共享只读几何与拓扑。
- 自定义求解器接收矩阵与右端的副本，可原地处理自己的输入；内部残差数据保持独立。
- 同一空间中的多个求解器交替使用、同一实例重复时间求解已验证。
- 当前后端改为 PyTorch 后，复用 NumPy 求解器会给出明确异常，并保持调用者选择的后端。
- 示例在 main 入口执行，导入示例不会启动计算或切换后端。

验证脚本为 `verify_compatibility.py`，结果分别在 `results_extension/compatibility_installed.json` 和 `compatibility_local.json`。P2 独立多项式含时算例误差约 1e-15。另对主验证脚本重新运行空间和时间收敛实验。

## 限制

兼容结论限于上述两套环境、NumPy/CPU、盒形区域和连续 P1/P2。没有运行 FEALPy 全库测试，不声称支持全部版本、后端或第三方库组合。独立应用模块并不等于完成官方模型注册或上游合并。验证与报告脚本属于直接运行的应用入口；核心可复用接口为 pde/CDRData 和 CDRLFEMSolver。

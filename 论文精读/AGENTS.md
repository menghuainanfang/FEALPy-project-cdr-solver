# 论文阅读工作区

## 目录约定

- 原始论文放在 `papers/`，不要修改原文件。
- 精读笔记放在 `notes/`。
- 一次性论文概览和组会简报放在 `briefs/`。
- 图表、思维导图和论文结构图放在 `figures/`。
- 最终交付物放在 `exports/`。
- 默认只在本项目目录内创建或修改文件。

## 工作流

- 论文总览、方法与贡献拆解：使用 `study-paper-brief`。
- 逐节、交互式精读：使用 `study-tutor`。
- 整理或补全笔记：使用 `study-notes`。
- 生成知识图谱或结构图：使用 `study-knowledge-visuals`。
- 完整学习闭环和复习沉淀：使用 `study-loop`。

## 输出要求

- 每篇进入精读流程的论文默认至少生成一份可独立阅读的 Markdown 文档；总览放在 `briefs/`，持续更新的交互学习记录放在 `notes/`。用户明确要求只聊不存时除外。
- 保留论文标题、作者、年份、来源及原始文件名。
- 明确区分论文原文结论、个人解释和待验证问题。
- 引用公式、图表或实验结果时标明页码。
- 不覆盖已有笔记；更新时保留已有有效内容。
